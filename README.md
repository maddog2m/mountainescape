# Mountain Escape Journey

Create a complete, professional, modern, fully responsive presentation website for a fictional hiking and mountaineering organization called **“The Mountain Escape”**, based in North Macedonia.

This website is a university project for the course **Business Practice 2025/2026 at FINKI**, so it must look like a real production-ready website for an active hiking and mountaineering organization, not like a simple student landing page.

The website should contain multiple pages, working navigation, functional interactive elements, responsive design, multilingual support, cookie consent, contact and membership forms, hiking tours, upcoming events, team members/guides, gallery, blog/news and detailed information about the organization.

## Technology

Use:

* React
* TypeScript
* Tailwind CSS
* Lucide icons
* React Router
* Reusable React components

The project should be easy to build and deploy.

Use local/static data where possible so the website works immediately after deployment.

Do not leave unfinished elements, TODOs, empty links, placeholder buttons or broken navigation.

Every visible button should have an actual purpose.
